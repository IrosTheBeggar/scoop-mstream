# scoop-mstream

Scoop bucket for [mStream](https://github.com/IrosTheBeggar/mStream) tools.

```powershell
scoop bucket add mstream https://github.com/IrosTheBeggar/scoop-mstream
scoop install mstream-player
```

installs [mstream-player](https://github.com/IrosTheBeggar/mstream-terminal-player) —
the terminal player and headless server-audio engine — from the prebuilt
release binaries, verified against each release's published sha256 manifest.
No admin rights, no SmartScreen dialog, and `scoop update mstream-player`
follows new releases.

The manifest is regenerated by `scripts/bump.sh` from each release's
`manifest.json` — the player repo's release workflow pushes the bump here
automatically, so this bucket follows releases on its own.
